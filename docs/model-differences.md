# Model differences

## Fat

![PS3 Fat](/assets/images/consolemodels/PS3-Fat.png)

The original PlayStation 3 Model. This models usually aren't too reliable due to the defective RSX 90/65nm GPU chip that is on their motherboard, plus the bad cooling and high consumption.

* [CECHBxx](https://www.psdevwiki.com/ps3/CECHBxx)
